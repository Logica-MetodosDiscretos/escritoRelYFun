Sección 1 · Producto cartesiano y relaciones binarias

Pares ordenados, cardinalidad, relaciones por extensión y comprensión

10 puntos · Preguntas 1–8
Pregunta 1 · Verdadero o Falso · 1 punto
Sea A = {m, n} y B = {1, 2, 3}.
El producto cartesiano A×B = {(m,1), (m,2), (m,3), (n,1), (n,2), (n,3)}.
Pregunta 2 · Opción múltiple · 1 punto
Sea A = {x, y, z} y B = {1, 2}.
¿Cuántos pares ordenados tiene A × B?
Pregunta 3 · Verdadero o Falso · 1 punto
Sea A = {1, 2, 3}.
La relación R = {(1, 2), (2, 4), (3, 1)} está bien definida en A × A.
Pregunta 4 · Selección múltiple · 2 puntos
Sea A = {1, 2, 3} y B = {2, 4}.
Marcá todos los pares que pertenecen a A × B.
Pregunta 5 · Selección múltiple · 2 puntos
Dado A = {a, b, c}, marcá todas las relaciones que están bien definidas sobre A × A.
Pregunta 6 · Opción múltiple · 1 punto
Sea A = {1, 2, 3, 4}. Se define la relación
R = { (x, y) / (x, y) ∈ A×A y x + y = 5 }
¿Cómo queda R escrita por extensión?
Pregunta 7 · Opción múltiple · 1 punto
Sea A = {0, 1, 2, 3}.
Se define R = { (x, y) / (x, y) ∈ A×A y x · y = 0 }
¿Cuál de estas opciones es un par que pertenece a R?
Pregunta 8 · Verdadero o Falso · 1 punto
Sea A = {2, 4, 6}. Se define la relación
R = { (x, y) / (x, y) ∈ A×A y x < y }
El par (4, 6) pertenece a R.

Sección 2 · Funciones Java con retorno

Tipos de retorno, llamadas, paso por valor, completar código

10 puntos · Preguntas 9–15
Pregunta 9 · Opción múltiple · 1 punto
¿Qué imprime en consola el siguiente programa?
public static int triple(int x) {
    return x * 3;
}

public static void main(String[] args) {
    System.out.println(triple(4));
}
Pregunta 10 · Opción múltiple · 1 punto
¿Qué imprime en consola el siguiente programa?
public static int resto(int a, int b) {
    return a - b;
}

public static void main(String[] args) {
    int r = resto(10, 3);
    System.out.println(r + 1);
}
Pregunta 11 · Opción múltiple · 2 puntos
¿Qué imprime en consola el siguiente programa?
public static int reducir(int n) {
    n = n - 3;
    return n;
}

public static void main(String[] args) {
    int k = 9;
    int res = reducir(k);
    System.out.println(k + " " + res);
}
Pregunta 12 · Opción múltiple · 2 puntos
El método mayor debe devolver el mayor de dos números enteros.
¿Qué línea debe ir en lugar de ___ para que funcione correctamente? 
public static int mayor(int a, int b) {
    if (a > b) {
        return a;
    }
    return ___;
}
Pregunta 13 · Verdadero o Falso · 1 punto
El siguiente método compila sin error: 
public static int cociente(int a, int b) {
    return a / b;
}
Pregunta 14 · Opción múltiple · 1 punto
El siguiente código no compila. ¿Cuál es el motivo? 
public static int cuadrado(int n) {
    System.out.println(n * n);
}

public static void main(String[] args) {
    int r = cuadrado(5);
    System.out.println(r);
}
Pregunta 15 · Verdadero o Falso · 1 punto
El siguiente método está correctamente declarado y compila sin error: 
public static double precio(int cantidad, double valorUnitario) {
    return cantidad * valorUnitario;
}
